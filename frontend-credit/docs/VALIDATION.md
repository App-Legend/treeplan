# 검증 기록

2026-10-17, Chromium 기반 Codex 브라우저에서 확인했습니다.

- TypeScript strict 검사와 Vite 프로덕션 빌드.
- PC 1440px 및 모바일 390px에서 24개 상태씩 총 48개 확인: 문서 가로 넘침 없음, 깨진 이미지 없음.
- 320 / 767 / 768 / 1024px에서 시작·트리·결과·로그인·히스토리 5개 대표 상태의 가로 넘침 추가 확인.
- 시작 → 카테고리 선택 → 가지 확장 → 단어 3개 고정 → 생성 → 결과물 흐름.
- 결과물 직접 수정 후 새로고침 시 보존, 세부안 보완 완료 표시.
- 로그인 폼 오류와 데모 로그인, 히스토리 검색.
- Markdown 실제 다운로드 및 한글 본문 확인.
- 대표 PC/모바일 화면의 시각 검토. 콘솔 오류/경고 없음.
- Figma SVG를 로컬 파일로 포함하고, 폰트를 WOFF2로 변환해 약 22.8MB에서 4.9MB로 축소.

## 검증 한계

Safari/Firefox 및 실제 휴대기기에서 별도로 검사하지 않았습니다. 터치 제스처는 구현되어 있으나 실제 기기의 멀티터치 검증은 하지 않았습니다. TXT는 MD와 동일한 다운로드 경로를 사용하지만 별도 파일 저장 확인은 하지 않았습니다. PDF는 인쇄 스타일과 브라우저 인쇄 기능을 사용하며 실제 PDF 저장까지 자동 검사하지 않았습니다. 인증·AI·협업 서버는 범위에 포함되지 않아 관련 서버 통합 검사는 없습니다.
